# Artikulata
Make learning possible anytime and everywhere. Artikulata is an app intended for children from 3-6 years old with speech delay. This app focuses on improving child's articulation which is one of the causes of speech delay. Video of words articulation and word articulation checker are provided in the app as solution to assist in improving children's articulation.

**Artikulata's features:**
- Video of words articulation
- Word Articulation Checker Using Machine Learning
- Cat Gallery

**Frameworks/Tech that I use:**
* SwiftUI
* MVVM Architecture
* CreateML
* SoundAnalyzer
* AVFoundation
* Lottie
